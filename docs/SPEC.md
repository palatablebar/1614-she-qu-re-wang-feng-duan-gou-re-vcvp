# 数据与模型契约

先看字段单位和历史截止，再解释预测与排班。

## 现场观测

| 字段 | 含义 | 单位 | 样本常见范围 |
| --- | --- | --- | --- |
| `ambient` | 外温 | ℃ | -17–12 |
| `area` | 供热面积 | 万㎡ | 4–75 |
| `return_temp` | 回水温度 | ℃ | 28–61 |
| `reserve` | 储热余量 | MWh | 0–46 |
| `wind` | 风速 | m/s | 0–23 |
| `occupancy` | 入住热负荷比例 | % | 34–99 |

## 可见性与结果

`day` 为业务序列日，`received` 是录入日期。`revision` 只在可见窗内选最大版，同版内容冲突整键隔离。`arrival` 和 `window` 用当日分钟表示，分派沿半开区间，片区和 `pool` 标识不同业务位置。

历史结果字段 `target` 表示峰段购热兆瓦时，`outcome_day` 是结果首次可见日。`complete=0` 的不完整单据不参与普通标签回放，清线模型按右截尾留作下界。结算项目的 `target` 是参考发电量，`confirmed` 表示实测表计偏差是否被稽核确认。

## 带天气交互的岭回归

用覆盖面积、暖度和低回温交互构造基函数。只用训练窗的尾段选择 L2 强度，最终在训练窗全量重估，再按片区样本量收缩残差。

预测和误差带采用业务原始单位，采用校准窗绝对误差的有限样本分位。

特征中位和尺度只在训练窗估计。无已知片区、缺关键测量或超出训练支撑会转人工。归因记录单轴回到训练参考值后对原始分数的变化。

## 寒潮班次的证据与申报裁决

历史样本分布偏暖时，常规岭回归对寒潮峰段会系统性低估。系统按下列规则处置：

1. **偏暖分布识别（`weather_drift`）**：以训练窗外温下十分位为历史偏暖基线，当班跌破基线的单据占比达到 25% 且超过历史尾部两倍时判定寒潮，写入 `cold_wave` 并将发布就绪降为复核。
2. **外片区补证（`analog_evidence`）**：外温为主、风速为次计算标准化天气距离，只从其他片区已确认的历史实测中取最近邻。至少 3 条、最近距离不超过 0.55、且覆盖两个以上外片区才给出 `supported` 旁证预测与带宽；不足为 `weak`，没有为 `no_analog`，后两者不能定量。
3. **本片区误差带（`nomination_policy`）**：误差带只取本片区旧班实测的有限样本分位（至少 7 条确认样本）；样本不足时显式借用全局校准带并把证据降级。外片区旁证永远不能替代本片区误差带。
4. **缓报规则**：误差带跨过该单据最小申报量，或证据等级不足时，只申报拿得准的保供下限（`confirmed_units`），其余计入 `held_units` 缓报；已确认保供照常申报。
5. **可中断合同全停**：`interruptible_off` 打开后保供下限必须兑现，超过下限的可中断补量全部缓报。
6. **保证量只占一次（`CoverLedger`）**：储热保证量与热源保证量分两个资源池跨单据记账，同一资源池已占用容量不得在后续单据重复抵扣，重复占用记入 `*_duplicate`。
7. **迟到实测隔离（`nomination_replay.replay_shift`）**：按决策时点 `asof` 回放，`outcome_day >= asof` 的实测在当班不可见，只能进入后续班次；回放还原的当班购热量不被迟到数据改写。

## 资源和发布

一单位资源为外购热兆瓦时。锁定已确认的储热和热源保证量，拆分保供与可中断补量。
预算等于已用、可用剩余、预留三者之和。发布复核固定模型和源摘要，同时检查当前版本。已发布内容通过不可变标识回看。
